## Markdown dialect for report/md (parsed by build_docx.py; Phase 2 converts to LaTeX)
- File `NN_name.md`; first line `# Chapter Title` (builder prints "Chapter N"). Front matter/appendix files use `# ` too; builder knows which are unnumbered.
- `##` / `###` sections -> numbered N.M / N.M.K automatically.
- Inline: **bold**, *italic*, `code`. Unicode for symbols in prose (σ, ≥, ∀).
- Lists: `- ` bullets, `1. ` numbered.
- Figure: `![Caption text.](name.png){#fig:key}` own line (file in report/figures).
- Table: line `Table: Caption text. {#tab:key}` then a pipe table.
- Display equation: `$$ LaTeX $$ {#eq:key}` on one line (docx: matplotlib mathtext image; keep LaTeX simple).
- Cross-refs: `@fig:key`, `@tab:key`, `@eq:key`, `@sec:key` (sections: `## Title {#sec:key}`).
- Citations: `[@key]` or `[@a; @b]` -> IEEE numbers in order of first citation; entries in report/md/references.json.
- Code: fenced ``` blocks.
- Page break: line `\newpage`.
