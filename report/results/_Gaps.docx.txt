1. Paper 1 — Normalization-Aware Isotonic Calibration
Paper's method
Paper 1 focuses on multiclass probability calibration.
It proposes:
FIR — Flattened Isotonic Regression
and
NA-FIR — Normalization-Aware Flattened Isotonic Regression
The important difference is that NA-FIR accounts for the normalization/collateral effects between class probabilities, rather than calibrating every class independently. It uses PAVA for initialization and then uses MCMC/simulated annealing because the normalized optimization is no longer convex.
It also proposes:
SCIR — Sorted Cumulative Isotonic Regression
which incorporates ranking/order information into calibration.
